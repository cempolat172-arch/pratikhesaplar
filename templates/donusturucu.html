Hepsi Bir Arada Format Dönüştürücü Nedir ve Neden Kesinlikle Ücretsiz?

        
İnternette görseli WebP yapma, fotoğrafı PDF'e çevirme veya CSV to JSON gibi araçları arattığınızda karşınıza çıkan sitelerin neredeyse tamamı belirli bir kullanım limitine sahiptir. İki dosya dönüştürdükten sonra sizden "Premium" üyelik isterler veya PDF dosyalarınızın üzerine kocaman kendi logolarını basarlar. Pratikhesaplar.com olarak bu duruma son veriyoruz!

        
Geliştirdiğimiz bu "Hepsi Bir Arada Format Dönüştürücü" platformu, %100 ücretsiz, sınırsız ve programsızdır. Hiçbir şekilde üyelik gerektirmez, dosya indirme sınırı yoktur ve dönüştürdüğünüz PDF'lerin üzerine asla reklam filigranı (watermark) eklenmez. Tüm araçlarımız sınırsız bir şekilde her zaman bedava kalacaktır.


        
1. Kalite Kaybı Olmadan Görseli WebP'ye Çevirme

        
Bir web siteniz varsa veya sadece depolama alanından tasarruf etmek istiyorsanız, standart JPG ve PNG dosyalarınızı yeni nesil WebP formatına dönüştürmeniz şarttır. Google'ın bizzat geliştirdiği WebP formatı, resim kalitesini gözle görülür şekilde bozmadan dosya boyutunu %80'e varan oranlarda küçültür.

        
Aracımız sayesinde hiçbir program (Photoshop vb.) kurmadan, devasa boyutlu görsellerinizi saniyeler içinde ücretsiz WebP çevirici modülümüzle sıkıştırabilirsiniz. İşlem tamamen tarayıcınızda gerçekleştiği için anında sonuç alırsınız.


        
2. Fotoğrafları Tek Bir PDF Dosyasında Birleştirme

        
İş başvurularında, okul ödevlerinde veya resmi belge gönderimlerinde birden fazla fotoğrafı (kimlik arkalı önlü, faturalar vb.) karşı tarafa tek tek yollamak profesyonel değildir. Görselden PDF yapma aracımızla, istediğiniz kadar fotoğrafı (JPG, PNG vb.) sisteme yükleyebilir ve tek bir tıkla hepsini düzenli sayfalardan oluşan tek bir PDF belgesi haline getirebilirsiniz. Tamamen ücretsiz olan bu işlemde dosyalarınızın arasına reklam sayfaları eklenmez.


        
3. Metin İşlemleri: Karakter Sayıcı ve Base64 Şifreleme

        
Sosyal medya uzmanları (SEO), editörler ve yazılımcılar için özel olarak tasarladığımız metin düzenleyicimiz sadece bir kelime ve karakter sayıcı değildir. Aynı zamanda bozuk Türkçe karakter sorununu çözen, tüm metni tek tıkla büyük veya küçük harfe (tr-TR uyumlu) dönüştüren harika bir araçtır.

        
Buna ek olarak yazılımcıların ve güvenlik uzmanlarının sıklıkla başvurduğu Base64 Encode (Şifreleme) ve Decode (Çözme) işlemi de mevcuttur. API entegrasyonlarında veya veri gizleme süreçlerinde metinlerinizi saniyeler içinde Base64 formatına çevirebilir veya çözebilirsiniz.


        
4. Yazılımcılar İçin CSV'den JSON'a Dönüştürücü

        
Veri bilimiyle (Data Science) veya web programlamayla uğraşanlar çok iyi bilir: Excel'den dışa aktarılan virgülle ayrılmış veri dosyalarını (.csv) JavaScript ortamında (JSON) okumak her zaman eziyettir. Ücretsiz CSV to JSON dönüştürücü sekmemize gelin, CSV dosyanızı seçin ve anında bilgisayarınızın işlemci gücünü kullanarak yapılandırılmış, temiz bir JSON çıktısı (Array of Objects) elde edin. Bu işlem 10 bin satırlık Excel dosyalarında bile sadece milisaniyeler sürer.

function switchTab(tabId) {

function convertImage() {
    const fileInput = document.getElementById('imageInput');
    if (fileInput.files.length === 0) {
        alert('Lütfen bir görsel seçin!');
        return;
    }
    const file = fileInput.files[0];
    const reader = new FileReader();
    
    reader.onload = function(e) {
        const img = new Image();
        img.onload = function() {
            const canvas = document.createElement('canvas');
            canvas.width = img.width;
            canvas.height = img.height;
            const ctx = canvas.getContext('2d');
            ctx.drawImage(img, 0, 0);
            
            // WebP formatına çevir ve indir
            canvas.toBlob(function(blob) {
                const url = URL.createObjectURL(blob);
                const a = document.createElement('a');
                a.href = url;
                a.download = 'donusturulmus-goruntu.webp';
                a.click();
                URL.revokeObjectURL(url); // Clean up memory
            }, 'image/webp', 0.8);
        }
        img.src = e.target.result;
    }
    reader.readAsDataURL(file);
}

async function convertToPDF() {
    if (!window.jspdf) {
        alert("PDF kütüphanesi yükleniyor, lütfen 1 saniye bekleyip tekrar deneyin.");
        return;
    }
    const { jsPDF } = window.jspdf;
    const fileInput = document.getElementById('pdfImagesInput');
    if (!fileInput.files.length) return alert('Lütfen en az bir görsel seçin.');
    
    const doc = new jsPDF();
    
    for (let i = 0; i < fileInput.files.length; i++) {
        const file = fileInput.files[i];
        const dataUrl = await readFileAsDataURL(file);
        
        if (i > 0) doc.addPage();
        
        const imgProps = doc.getImageProperties(dataUrl);
        const pdfWidth = doc.internal.pageSize.getWidth();
        const pdfHeight = doc.internal.pageSize.getHeight();
        
        // Gorseli sayfaya sigdirma (aspect ratio koruyarak)
        const ratio = Math.min(pdfWidth / imgProps.width, pdfHeight / imgProps.height);
        const finalWidth = imgProps.width * ratio;
        const finalHeight = imgProps.height * ratio;
        
        const xOffset = (pdfWidth - finalWidth) / 2;
        const yOffset = (pdfHeight - finalHeight) / 2;
        
        doc.addImage(dataUrl, 'JPEG', xOffset, yOffset, finalWidth, finalHeight);
    }
    doc.save('pratikhesaplar_birlestirilmis.pdf');
}

function readFileAsDataURL(file) {
    return new Promise((resolve, reject) => {
        const reader = new FileReader();
        reader.onload = e => resolve(e.target.result);
        reader.onerror = reject;
        reader.readAsDataURL(file);
    });
}

function textOps(type) {
    const ta = document.getElementById('textInput');
    try {
        if (type === 'upper') ta.value = ta.value.toLocaleUpperCase('tr-TR');
        if (type === 'lower') ta.value = ta.value.toLocaleLowerCase('tr-TR');
        if (type === 'base64enc') ta.value = btoa(unescape(encodeURIComponent(ta.value)));
        if (type === 'base64dec') ta.value = decodeURIComponent(escape(atob(ta.value)));
    } catch(e) {
        alert("Geçersiz metin veya format.");
    }
    updateStats();
}

}
